# Десять парадных — демонстрационный сайт посуточной аренды

Пример сайта с онлайн-бронированием для собственников и управляющих компаний,
которые сдают квартиры посуточно. Компания, квартиры, цены и отзывы вымышлены.

## Что внутри

| Файл или папка | Что это |
| --- | --- |
| `index.html` | Главная: подбор по датам, схема центра, каталог из 10 квартир |
| `kvartiry/` | Отдельная страница на каждую квартиру с планом и расчётом цены |
| `pravila.html` | Правила проживания и частые вопросы |
| `assets/` | Оформление (`style.css`) и расчёт цены (`app.js`) |
| `data/apartments.json` | Тексты, цены и адреса квартир |
| `data/site.json` | Название, время заезда и выезда, залог, контакты разработчика |
| `tools/build.py` | Сборка страниц из данных |
| `tools/skyline.py` | Панорама достопримечательностей Петербурга на главной |

## Как поменять тексты и цены

1. Измените `data/apartments.json` или `data/site.json`.
2. Запустите `python3 tools/build.py`. Нужен только Python 3, без дополнительных библиотек.
3. Отправьте изменения в репозиторий: страницы обновятся на GitHub Pages.

Чтобы в блоке «Сделаю такой сайт для вас» появилась кнопка, впишите свой Telegram
в поле `developer.telegram` файла `data/site.json` и пересоберите сайт.

## Что в демо условно

- Вместо фотографий стоят планы квартир: они рисуются сборкой автоматически.
- Занятость дат не проверяется, цена считается по будним и выходным тарифам.
- Кнопка «Забронировать» ничего не отправляет. На рабочем сайте на этом шаге
  открывается модуль бронирования из системы управления.
- Страницы закрыты от поисковиков (`noindex`), чтобы вымышленную компанию не приняли за настоящую.

## Перенос на сайт клиента

GitHub Pages подходит только для демонстрации: его правила запрещают размещать на нём
коммерческие сайты. Сайт клиента нужно размещать на хостинге в России. Код переносится
без изменений, кроме адреса в `404.html`.
