# demo-posutochno

Демо-сайт «Апартаменты посуточно в Санкт-Петербурге» (10 объектов) — пример главной страницы для показа собственникам и управляющим.

## Файлы

- `index.html` — разметка главной страницы
- `styles.css` — стили (цвета и шрифты — в начале файла, в блоке `:root`)
- `script.js` — фильтр квартир и отправка формы бронирования в WhatsApp

## Структура главной

1. Плашка «Демо»
2. Шапка (закреплена): меню, телефон, «Написать», «Проверить даты»
3. Первый экран: заголовок + форма бронирования
4. Цифры-доказательства
5. Преимущества
6. Квартиры с фильтром
7. Акции
8. Поводы для поездки
9. Отзывы
10. Как добраться и условия
11. Финальный призыв: мессенджеры и Telegram-канал
12. Подвал
13. Нижнее меню на телефоне: «Квартиры / Даты / Написать»

## Что заменить на реальные данные

- Всё в квадратных скобках: `[Название]`, цены, рейтинг, время заезда, залог, реквизиты
- Номер WhatsApp — в `script.js` (`WHATSAPP_NUMBER`) и в ссылках `wa.me` в `index.html`
- Серые блоки «[Фото: …]» — на настоящие фотографии
- Блок карты — на виджет Яндекс Карт
